# 笔记模板

这里提供三个可复制的 Markdown 模板：`日记.md`、`读书笔记.md`、`文章笔记.md`。它们没有预填待办，不会把示例事项混入你的真实任务。

## 放在哪里

把这三个文件复制到笔记库的 `Templates/` 文件夹。不要把整个源码仓库作为自己的日常笔记库。

## 自动创建日记时使用

1. 在 Obsidian 的「设置 → 核心插件」启用「日记」。
2. 在核心「日记」设置中，将新建文件位置设为 `Daily`，日期格式设为 `YYYY/MM/YYYY-MM-DD`，模板文件位置选择 `Templates/日记.md`。
3. 打开「设置 → Daily → 日记 → 连接或调整日记」，点击「读取 Obsidian 日记设置」，确认路径预览后保存。
4. 使用核心「日记」的「打开/创建今天的日记」命令创建笔记，再回到 Daily 首页查看。

**Daily 的「打开今日笔记」及快速添加 Todo 在文件不存在时，仍使用插件内置格式，不会读取这个模板文件。** 上面的路径导入仅连接日记位置，不会导入模板。自定义模板需要由核心「日记」创建时应用；文件已经存在时不会重新套模板。

日记模板用 `{{date:YYYY-MM-DD}}` 填入日期和标题。通过核心「模板」手动插入时，它表示插入当天；补写历史日记时，请把日期属性和标题改成该笔记对应的日期。

## 手动插入读书或文章模板

1. 启用 Obsidian 核心「模板」，模板文件夹位置填写 `Templates`。
2. 在 `Library/Books/` 新建读书笔记，或在 `Library/Articles/` 新建文章笔记。
3. 打开命令面板，运行「模板：插入模板」，选择对应模板，然后填写内容。
4. 在 Daily 设置中开启资料库面板，确认文章和书籍目录与上面一致。

模板中的 `{{title}}` 是当前笔记名，`{{date:YYYY-MM-DD}}` 是插入时的日期。普通复制粘贴不会替换这些变量。模板本身没有 `type: book` / `type: article`，避免被当成资料库内容；实际笔记通过所在目录识别。若放在其他目录，可在实际笔记的属性中补充 `type: book` 或 `type: article`。

给已有日记插入完整模板可能重复标题和章节，优先在空白笔记中使用。默认待办章节为 `## 今日todo`，想法章节为 `## 想法/思考`；自定义名称时同步调整 Daily 设置。

如果以后在模板中添加了真实复选框任务，请到「设置 → Daily → 待办」把 `Templates` 加入排除目录，防止模板任务进入待办列表。

变量和核心插件行为可参考 [Obsidian 模板说明](https://help.obsidian.md/Plugins/Templates) 与 [核心日记说明](https://help.obsidian.md/Plugins/Daily+notes)。
