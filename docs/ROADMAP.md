# 路线图

Daily 聚焦每日笔记、待办、日历和月度计划。仓库为 [HappyChenchen/obsidian-dashboard](https://github.com/HappyChenchen/obsidian-dashboard)，插件 ID 保留 `dashboard-home`，以兼容已有安装。

## 当前能力

- 自由多标签、每行独立完成的月度计划、日记 Todo 聚合和安全写回。
- 日记目录引导、核心日记配置读取、日期子目录支持。
- 自动备份、导出恢复、同步冲突副本和草稿保护。
- 窄分栏布局、自定义首页、可选资料库与学习打卡。
- 可复现的安装包、贡献说明、CI 与草稿发布工作流。

## 下一步验证

1. Windows、Linux、iOS 和 Android 实机操作，尤其是输入、标签建议和触屏。
2. 最低支持 Obsidian 版本的兼容性。
3. 真实同步服务下的双设备切换、离线修改和并发冲突。
4. 大笔记库的启动时间、内存占用和刷新耗时。
5. 完成发布清单后发布试用版，再申请社区插件目录。

## 后续方向

- 中英文界面与说明。
- 提高任务在笔记重命名、插行后的排序稳定性。
- 明确更多任务插件语法的兼容范围。
- 继续拆分学习日历渲染与视图生命周期。

这些是候选方向，没有承诺完成日期。功能建议请先描述真实使用场景，避免把首页扩展成复杂的项目管理系统。
